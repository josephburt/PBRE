# PBRE

**Puffing Bluetooth Re-Engineered** — an open source web app for controlling Pax 3 vaporizers over the [Web Bluetooth API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Bluetooth_API).

This repository continues work started in [evertonstz/pax-romana](https://github.com/evertonstz/pax-romana). The original project is MIT-licensed; that license and copyright notice are preserved in `LICENSE`.

Original demo: https://evertonstz.github.io/pax-romana

If you want the Bluetooth protocol implementation, start in `src/pax` and `src/hooks/usePaxBluetoothServices/useBluetooth/useBluetooth.ts`.
